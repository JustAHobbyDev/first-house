# Console typefaces

These fonts implement the typography in the user-supplied
`RegnetConsoleRedesign.zip` console template. They are served locally; opening the
console does not request Google Fonts or another external font service.

- Source Sans 3, regular and semibold: Google Fonts CSS distribution, upstream
  `google/fonts` at `ofl/sourcesans3`. See `Source-Sans-3-LICENSE.txt`.
- IBM Plex Mono, regular and medium: Google Fonts CSS distribution, upstream
  `google/fonts` at `ofl/ibmplexmono`. See `IBM-Plex-Mono-LICENSE.txt`.

Both are distributed under the SIL Open Font License, version 1.1. Font binaries
are unmodified.
